# Motion Tracking Platform for Biomechatronics Education

This is the shared repository for Group 2's Senior Capstone Project

Our consensus was that developing the app using Kotlin, a more contemporary alternative to Java, would be preferable due to its improved safety and reduced verbosity.

Overarching project goal summary:
Develop an Android app that captures data from multiple WIT Motion IMUs and produces a visualization of that motion data.
There is existing source code which provides these functionalities separately, we are tasked with combining these functionalities into a single platform.
